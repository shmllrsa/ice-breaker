# Swipe!

A dating-app-style icebreaker on online sex culture.

## How to play

- Presenters show a statement or situation related to online sex culture.
- **Swipe right** if you think the behaviour or scenario is acceptable, healthy, or apparent in the online scene.
- **Swipe left** if you think it is unacceptable, harmful, or a red flag.
- Participants may explain their choices.

## Controls

- Drag the card, tap the ✕ / ✓ buttons, or press ← / →.
- Backspace (or the round arrow button) undoes the last swipe.
- **Edit cards** lets you replace the statements: one per line, with an optional talking point after a `|`.
- **Shuffle**, **Restart** and **Full screen** are in the top bar.

## Run it

It's a single `index.html` with no build step. Open it in a browser, or publish it with GitHub Pages:

1. Push these files to a repository.
2. Go to **Settings → Pages**, set the source to your main branch and the root folder.
3. Your site will be at `https://<your-username>.github.io/<repo-name>/`.
